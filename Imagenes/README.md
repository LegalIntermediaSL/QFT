# Imagenes

Este directorio reune los recursos visuales del proyecto: diagramas, esquemas, figuras de apoyo, capturas y exportaciones listas para insertarse en el tutorial o en los cuadernos.

## Estructura

- `diagramas/`: diagramas conceptuales, mapas visuales y graficos explicativos.
- `figuras/`: imagenes finales integradas o pensadas para integrarse en el tutorial.
- `referencias/`: imagenes fuente, borradores visuales o material de apoyo.
- `exportadas/`: versiones renderizadas o listas para publicacion.

## Uso sugerido

Esta carpeta debe servir como complemento visual de `Tutorial/` y `Cuadernos/`.

Flujo recomendado:

1. guardar una imagen fuente o borrador en `referencias/` o `diagramas/`;
2. preparar una version limpia para uso pedagogico;
3. mover la version final a `figuras/` o `exportadas/`;
4. enlazarla desde el tutorial o desde un notebook.

## Criterios practicos

- usar nombres descriptivos y consistentes;
- preferir formatos ligeros cuando no se pierda legibilidad;
- si una imagen corresponde a un capitulo concreto, reflejarlo en el nombre;
- evitar acumular imagenes sin contexto o sin destino claro.
