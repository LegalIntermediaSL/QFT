    Leyenda

    • Fundacional: fija lenguaje y conceptos base.
    • Nucleo: forma el cuerpo minimo de una primera QFT.
    • Intermedio: amplifica formalismo y lectura moderna.
    • Avanzado: conecta con fenomenologia y fronteras actuales.
    • Solido: modulo suficientemente desarrollado para lectura continua.

    • Usa esta pagina si quieres ver el mapa completo antes de empezar.
