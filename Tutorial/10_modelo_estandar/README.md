## Papel dentro del curso

Este bloque debe leerse como lectura avanzada. No reemplaza el estudio gradual de gauge, fermiones, Higgs y renormalizacion, pero sirve como vista panoramica del destino final del recorrido.

## Resultado esperado

Al terminar este modulo, deberia quedar claro:

- como se reparte el lagrangiano del Modelo Estandar por sectores;
- por que la interaccion debil es quiral;
- como el mecanismo de Higgs genera masas gauge sin romper la estructura gauge de forma explicita;
- como la mezcla electrodébil organiza el foton, el boson $Z$ y el angulo de Weinberg;
- como el sector de Yukawa produce masas fermionicas y mezcla entre generaciones;
- como se leen las corrientes cargadas y neutras del sector electrodébil;
- por que el sector de neutrinos apunta mas alla del Modelo Estandar minimo y como se conecta con PMNS y oscilaciones.

## Ejercicios sugeridos

1. Explica por que el grupo gauge del Modelo Estandar se organiza como $SU(3)_c \times SU(2)_L \times U(1)_Y$ y que sector fisico corresponde a cada factor.
2. Deriva de forma esquematica como la mezcla entre $W^3_\mu$ y $B_\mu$ produce el foton y el boson $Z$.
3. Usa el vacio del Higgs para justificar las relaciones $m_W = gv/2$ y $m_Z = v\sqrt{g^2+g'^2}/2$ a nivel estructural.
4. Explica por que la interaccion debil es quiral y como esa quiralidad se refleja en corrientes cargadas y neutras.
5. Describe la diferencia conceptual entre masas generadas por Yukawas y masas gauge generadas por el mecanismo de Higgs.

## Ampliaciones prioritarias

- separar estructura gauge, sector fermionico y sector de Higgs;
- desarrollar quiralidad, Yukawas y masas;
- añadir un mapa minimo de observables y fenomenologia;
- conectar con tablas y datos del PDG;
- ampliar mezcla electrodébil, corrientes y acoplamientos efectivos.
- profundizar neutrinos, oscilaciones y escenarios de masas de Majorana.

## Lecturas y referencias recomendadas

- Introductorio: Tong, notas de gauge y panorama del Modelo Estandar.
- Intermedio: Schwartz o Peskin para la arquitectura del lagrangiano.
- Consulta: Particle Data Group para parametros, masas y convenciones experimentales.
