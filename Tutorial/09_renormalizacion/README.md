# Modulo 09: Renormalizacion

## Objetivo

Este modulo reunira regularizacion, contraterminos, escala de renormalizacion y grupo de renormalizacion.

## Contenido previsto

1. origen de las divergencias ultravioletas;
2. regularizacion y renormalizacion;
3. teorias renormalizables y efectivas;
4. corrida de acoplamientos;
5. interpretacion fisica de la dependencia en escala.
