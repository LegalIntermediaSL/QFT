# Borradores del Tutorial

Esta carpeta reúne variantes editoriales, resúmenes alternativos y versiones en revisión que no forman parte de la navegación pública del tutorial.

## Criterio de uso

- Aquí van borradores o versiones alternativas de capítulos ya existentes.
- La estructura interna debe reflejar el módulo original para que sea fácil comparar contenido.
- El sitio público generado con MkDocs excluye esta carpeta.

## Convención editorial

- La versión publicada y canónica vive fuera de `_borradores/`.
- Si un borrador madura y reemplaza al capítulo público, conviene promoverlo explícitamente y archivar o eliminar la versión anterior.
