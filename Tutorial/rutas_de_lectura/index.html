    Rutas de Lectura del Tutorial

    Esta pagina organiza el tutorial por perfiles y objetivos. La idea no es sustituir el indice general, sino ayudar a elegir un camino razonable segun el tiempo disponible y el tipo de lectura buscada.

    Para usar mejor estas rutas, conviene combinarlas con:

    • Tabla maestra del tutorial, si quieres ver de un vistazo que modulos son nucleares y cuales son avanzados.
    • Catalogo de capitulos y etiquetas, si necesitas afinar la entrada a nivel de capitulo.
    • Problemas recomendados por semana, si quieres transformar una ruta en rutina activa.

    5. 04 Cuantizacion del campo escalar

    7. 06 Fermiones y Dirac

    11. 10 Modelo Estandar

    Ruta minima

    Si quieres una primera pasada compacta con el mayor retorno conceptual:

    1. 00 Prerrequisitos
    2. 01 Fundamentos conceptuales
    3. 02 Relatividad y campos
    4. 03 Accion y simetrias
    5. 04 Cuantizacion del campo escalar
    6. 05 Interacciones y perturbaciones
    7. 06 Fermiones y Dirac
    8. 07 Gauge y QED

    Esta ruta deja armado el nucleo duro de la QFT relativista perturbativa.

    Si tienes muy poco tiempo

    Si solo quieres una panoramica razonable del curso, usa esta secuencia:

    1. 01 Fundamentos conceptuales
    2. 03 Accion y simetrias
    3. 04 Cuantizacion del campo escalar
    4. 05 Interacciones y perturbaciones
    5. 07 Gauge y QED

    Si despues quieres seguir, el siguiente modulo natural es 09 Renormalizacion.

    Ruta para consulta rapida

    Si ya conoces la base y quieres entrar por temas:

    • Para scattering: 05 Interacciones y perturbaciones
    • Para teorias gauge: 07 Gauge y QED
    • Para running y escalas: 09 Renormalizacion
    • Para Modelo Estandar: 10 Modelo Estandar
    • Para informacion y agujeros negros: 11 QFT, informacion y agujeros negros
    • Para EFT: 12 Teorias de campo efectivas

    Como usar estas rutas

    • Si es tu primera vez, empieza por la ruta minima o la recomendada completa.
    • Si vienes de mecanica cuantica y relatividad, probablemente puedas entrar desde el modulo 01 o 03.
    • Si tu objetivo es fenomenologia, prioriza los modulos 05 a 10.
    • Si tu objetivo es frontera conceptual, usa 08, 09 y 11 como eje.
    • Si quieres decidir a nivel de capitulo, entra despues al README del modulo y usa la seccion Capitulos imprescindibles en primera pasada.
